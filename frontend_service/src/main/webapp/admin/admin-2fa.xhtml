A chaque connexion, un code vous sera demande apres le mot de passe.

ℹ️ Comment ca marche ?

1
Installez une application
Google Authenticator, Authy, ou toute app compatible TOTP.
2
Scannez le QR code
L'app genere un code a 6 chiffres qui change toutes les 30 secondes.
3
Connexion en 2 etapes
Apres le mot de passe, entrez le code de votre application pour acceder a votre espace admin.
⚠️

Conservez votre secret en lieu sur. Si vous perdez acces a votre application, un administrateur devra reinitialiser votre 2FA.
