Format du fichier CSV

Fichier texte avec séparateur point-virgule (;). La première ligne est l'entête (obligatoire). Encodage : UTF-8. 

nom;prenom;email;role;motDePasse
Diallo;Mamadou;mamadou@example.com;PARTICULIER;MonMdp123!
Ndiaye;Fatou;fatou@example.com;AGENT;AgentPass456!
Fall;Ibrahim;ibrahim@example.com;PARTICULIER;

* Les colonnes role et motDePasse sont optionnelles (défauts : PARTICULIER / Changeme123!).
* Les emails déjà existants sont ignorés silencieusement.
