# SenExpertFormation — Application web de gestion des formations

Développement d'une application web permettant de centraliser la gestion des utilisateurs et des activités liées aux formations, notamment les offres de formation, les demandes et le suivi des candidatures.

## Fonctionnalités et architecture

- Mise en place d'une architecture microservices pour séparer les fonctionnalités liées aux utilisateurs et aux formations.
- Développement des services backend avec Java et Spring Boot.
- Centralisation du routage des requêtes avec Spring Cloud Gateway.
- Gestion des données avec PostgreSQL et conteneurisation des services avec Docker et Docker Compose.

## Technologies

Java, Spring Boot, Spring Cloud Gateway, JSF, PrimeFaces, PostgreSQL, Docker, Docker Compose.

## Lancement

```bash
git clone https://github.com/Bineta-Sy/SenExpertFormationMicroservices.git
cd SenExpertFormationMicroservices
docker compose up --build
```
